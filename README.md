# دعوة زفاف يونس ونور

نسخة أولية لموقع دعوة زفاف إلكترونية.

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح.

## الموسيقى
ضع ملف الأغنية داخل نفس المجلد باسم:
`music.mp3`

المتصفحات عادة لا تسمح بتشغيل الصوت تلقائياً بدون تفاعل المستخدم،
ولهذا يبدأ تشغيل الموسيقى عند الضغط على ختم الظرف.

## تعديل الموقع
رابط Google Maps موجود داخل `index.html`.
يمكن استبداله برابط القاعة الدقيق.

## الملفات
- index.html
- style.css
- script.js
- music.mp3 (يضاف لاحقاً)
